# BugReplay engineering preview

Create a 52-second, silent, caption-led 1280×720 HyperFrames video. The subject is the implemented product UI, controlled shop, and real deterministic engineering evaluation. It is not the final hackathon demonstration and does not claim autonomous model discovery.

Persistent on-screen wording: **Scripted engineering preview · no live model run**.

Use the actual clean UI screenshot, actual shop screenshot, original three-second saved Playwright replay, and actual evaluation artifacts. Show the expected behavior, two matching buggy assertion failures, one unchanged-file corrected-control pass, and remaining live-model, neatlogs, cfo.ai and final-demo gates. Never animate a fake cursor, inject a synthetic success into the product, invent metrics, or imply that a prerecorded clip is live.

Local assets only; no paid generators, synthetic voice, music, stock imagery, or external account publishing. Deliberate silence keeps the technical captions readable. The user authorized creation and rendering; no additional render approval is needed.

## Assets

The bundler accepts explicit paths to a reviewed UI screenshot, shop screenshot, and an actual `artifacts/product-eval` directory. It validates the summary and saved-test digest before staging selected review-safe copies. Original source media is preserved. A separate setup script fetches pinned GSAP 3.14.2 with hash verification; HyperFrames embeds its built-in Inter font.

## Limits

Known-condition scripted tests are engineering evidence. They are not three autonomous investigations, a live-model benchmark, sponsor evidence, or a completed hackathon submission. Cost and live success-rate claims are excluded.
